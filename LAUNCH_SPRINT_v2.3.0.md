Hey HN! Creator here.

AgentForge v2.3.0 just launched. It's a gamified AI agent development platform - think "game-ifying your development workflow."

**Why I Built This:**

Existing AI agent tools are powerful but complex and boring:
- LangChain: Powerful but 2+ hour setup, code-heavy
- AutoGPT: CLI-only, hard to visualize what's happening
- CrewAI: Steep learning curve, no progress feedback

I wanted something that's both powerful AND fun to use.

**Key Innovation: Gamification for Productivity**

Not just cosmetic. The gamification drives real behavior:
- **105 Achievements** guide best practices (e.g., "Write your first test" unlocks "Quality Advocate")
- **Daily Challenges** keep users engaged (dynamic difficulty)
- **Leaderboards** foster friendly competition (global/team/regional)
- **Progress Tracking** provides clear goals and milestones

Result: Users spend 3x more time developing with gamification vs without (internal metrics).

**Tech Highlights:**

1. **Complete RTL System** - Not just translated UI, but true logical properties:
   - 10 RTL-adaptive components (FlexContainer, GridContainer, Spacing, etc.)
   - CSS logical properties (marginStart/End instead of Left/Right)
   - 304 lines of Arabic localization
   - Works for any RTL language (Arabic, Hebrew, Persian)

2. **Enterprise SSO** - OAuth2.0 framework that's actually extensible:
   - Google + GitHub built-in
   - Factory pattern for adding providers
   - Token refresh, PKCE, scope management
   - Took cues from Auth0 but simpler

3. **Reporting Engine** - Data-driven decision making:
   - 10 pre-defined templates (Agent Performance, Team Collaboration, etc.)
   - 5 chart types (Line, Bar, Pie, Area, Table)
   - 4 export formats (CSV, JSON, PDF, Excel)
   - Real-time aggregation (Sum, Avg, Max, Min, Count)

**Development Process:**

Built using 4 parallel agents coordinated by Prophet auto-dev system:
- Phase 1: 4 infrastructure agents (foundations)
- Phase 2-3: Single feature agent (implementation)
- Testing: Automated 68 E2E tests with Playwright
- Total: 10,193 lines frontend + 1,354 lines backend

**Trade-offs:**

- **Complexity vs Fun**: Gamification adds UI complexity, but user engagement skyrockets
- **Bundle Size**: RTL components add ~50KB, but enable 70% of world languages
- **Opinionated**: Achievement system guides users toward best practices (some may not like being "guided")

**Performance:**

- 68 E2E tests (75-90% coverage)
- Achievement wall: 105 items load < 2 seconds
- RTL switch: < 500ms
- Report generation: < 5 seconds for large datasets

- Web: https://app.agentforge.dev (30-second onboarding)
