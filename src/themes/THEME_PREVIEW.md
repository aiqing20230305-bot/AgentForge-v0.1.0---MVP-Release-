## 主题对比

### 明暗对比
```
Dark   ████████████████ ← 深色背景，高对比度
Light  ░░░░░░░░░░░░░░░░ ← 浅色背景，柔和对比

### 色彩风格
```
Dark    → 经典专业
Light   → 清新明快
Neon    → 炫酷未来
Forest  → 自然舒适
Ocean   → 平静专注
```

```
🌙 夜间 (18:00 - 06:00)
   推荐: Dark, Neon, Ocean

## 技术细节

### CSS Variables 列表
```css
/* 背景 */
--color-bg-primary
--color-bg-secondary
--color-bg-tertiary

/* 文本 */
--color-text-primary
--color-text-secondary
--color-text-muted

/* 主色调 */
--color-accent-primary
--color-accent-secondary
--color-accent-tertiary

/* 边框 */
--color-border-primary
--color-border-secondary

/* 阴影 */
--shadow-primary
--shadow-secondary
--shadow-glow
```

### Tailwind 映射
```javascript
'bg-primary'     → var(--color-bg-primary)
'text-primary'   → var(--color-text-primary)
'accent-primary' → var(--color-accent-primary)
'border-primary' → var(--color-border-primary)
```
