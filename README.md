## 🎯 什么是 AgentForge？

> **AgentForge 是一个游戏化的 AI Agent 开发训练平台**
>
> 我们将枯燥的 AI Agent 开发，变成像培养 RPG 角色一样有趣的体验。
> 让你的 Agent 升级、进化、对战，在游戏中学习，在实战中成长。

## 🚀 5分钟上手

### 第 1 步：安装（1分钟）

```bash
# 克隆仓库
git clone https://github.com/aiqing20230305-bot/AgentForge.git
cd AgentForge

# 安装依赖
npm install

# 启动应用
npm run dev
```

### 第 2 步：创建你的第一个 Agent（2分钟）

1. 点击 "**新建 Agent**" 按钮
2. 从 **10 个模板**中选择一个（推荐：智能客服）
3. 自定义名称、头像、性格
4. 点击"**创建**" - 完成！

### 第 3 步：训练和进化（2分钟）

1. 给你的 Agent 分配任务
2. 观察它的**实时生命值**和**经验值**
3. 完成任务后自动升级
4. 解锁**技能树**，变得更强大

🎉 **恭喜！** 你已经创建并训练了你的第一个 AI Agent！

## 🚀 部署指南

### 开发环境

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# TypeScript 类型检查
npm run type-check

# 代码格式化
npm run format
```

### 生产构建

```bash
# 构建桌面应用
npm run build

# 仅构建 Web 版本
npm run build:web

# 打包 Electron 应用
npm run dist

# 打包所有平台
npm run dist:all
```

### Docker 部署

```bash
# 构建镜像
docker build -t agentforge .

# 运行容器
docker run -p 3000:3000 agentforge
```
