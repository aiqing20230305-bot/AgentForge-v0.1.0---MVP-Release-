## 🚀 5分钟上手

### 第 1 步：安装（1分钟）

```bash
# 克隆仓库
git clone https://github.com/aiqing20230305-bot/AgentForge.git
cd AgentForge

# 安装依赖
npm install

# 启动应用
npm run dev
```

### 第 2 步：创建你的第一个 Agent（2分钟）

1. 点击 "**新建 Agent**" 按钮
2. 从 **10 个模板**中选择一个（推荐：智能客服）
3. 自定义名称、头像、性格
4. 点击"**创建**" - 完成！

### 第 3 步：训练和进化（2分钟）

1. 给你的 Agent 分配任务
2. 观察它的**实时生命值**和**经验值**
3. 完成任务后自动升级
4. 解锁**技能树**，变得更强大

🎉 **恭喜！** 你已经创建并训练了你的第一个 AI Agent！

#### 🤝 Team管理和RBAC权限系统

**企业级团队协作和细粒度权限控制**

**7个完整API端点：**
```typescript
POST   /api/teams              // 创建团队
GET    /api/teams/:id          // 获取团队详情
PATCH  /api/teams/:id          // 更新团队信息
DELETE /api/teams/:id          // 删除团队
POST   /api/teams/:id/members  // 添加成员
DELETE /api/teams/:id/members/:userId  // 移除成员
GET    /api/teams              // 列出用户所有团队
```

**5种内置角色：**

| 角色 | 权限 | 使用场景 |
|------|------|---------|
| **Owner** | `*` (全部) | 团队创建者 |
| **Admin** | `team:*`, `agent:*`, `task:*` | 团队管理员 |
| **Developer** | `agent:read/write/deploy` | 开发人员 |
| **Analyst** | `analytics:*` | 数据分析师 |
| **Viewer** | 只读权限 | 观察者 |

**权限中间件：**
```typescript
// 单一权限检查
app.post('/api/teams', requirePermission('team:write'), createTeam);

// 任意权限（OR逻辑）
app.get('/api/dashboard',
  requireAnyPermission(['team:read', 'agent:read']),
  getDashboard
);

// 所有权限（AND逻辑）
app.delete('/api/teams/:id',
  requireAllPermissions(['team:delete', 'team:write']),
  deleteTeam
);
```

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# TypeScript 类型检查
npm run type-check

npm run format
```

```bash
# 构建桌面应用
npm run build

# 仅构建 Web 版本
npm run build:web

npm run dist

npm run dist:all
```

```bash
# 构建镜像
docker build -t agentforge .

docker run -p 3000:3000 agentforge
```
