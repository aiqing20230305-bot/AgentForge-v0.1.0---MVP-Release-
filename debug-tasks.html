调试任务数据

在浏览器控制台粘贴以下代码：

// 检查任务 store
const store = window.__ZUSTAND_STORES__?.taskStore || {}
console.log('selectedAgentId:', store.getState?.().selectedAgentId)
console.log('tasks count:', store.getState?.().tasks?.length)
console.log('filtered tasks:', store.getState?.().getFilteredTasks?.())
console.log('all tasks:', store.getState?.().tasks)
