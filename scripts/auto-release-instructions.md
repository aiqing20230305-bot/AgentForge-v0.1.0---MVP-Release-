## 📋 只需一个手动步骤（30秒）

### 步骤 1：创建 GitHub Token（30秒）

**点击此链接（已预填权限）：**
```
https://github.com/settings/tokens/new?description=AgentForge%20Release%20v1.1.0&scopes=repo
```

或者手动访问：
1. 访问：https://github.com/settings/tokens/new
2. **Token name**: `AgentForge Release v1.1.0`
3. **Expiration**: 7 days（建议）
4. **Select scopes**: 勾选 `repo`（完整仓库权限）
5. 点击页面底部的 **"Generate token"** 绿色按钮
6. **复制生成的 token**（格式：`ghp_xxxxxxxxxxxx`）

⚠️ **重要：Token 只显示一次，请立即复制！**
