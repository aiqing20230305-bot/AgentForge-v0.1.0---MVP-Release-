🚀 AgentForge 网页发布指南

只需在浏览器中操作，5 分钟完成！
步骤 1/3

📤 上传代码到 GitHub

方法 A：使用 Git 命令（推荐）

在终端执行（Git 会自动使用浏览器登录）：

cd ~/Downloads/world-of-claudecraft git push origin main git push origin v0.1.0 --force

💡 Git 会自动弹出浏览器让您授权，点击"Authorize"即可

方法 B：使用 GitHub Desktop（如果安装了）

  • 打开 GitHub Desktop
  • 选择项目
  • 点击"Push origin"

方法 C：网页上传（最后备选）

  • 访问：仓库页面
  • 点击"Add file" → "Upload files"
  • 拖拽整个 world-of-claudecraft 文件夹
  • 提交信息：AgentForge v0.1.0 MVP Release
步骤 2/3

🏷️ 创建 Release

  1. 访问 Release 页面：
    https://github.com/Summonair/world-of-claudecraft/releases/new
  2. 点击"Choose a tag"，输入：
    v0.1.0
    点击 Create new tag: v0.1.0 on publish
  3. 填写 Release title：
    AgentForge v0.1.0 - MVP Release 🎉
  4. 填写描述（点击下方按钮复制）：
  5. 点击绿色的"Publish release"按钮
步骤 3/3（可选）

⚙️ 优化仓库设置

1. 更新仓库名称：

  • Settings → General → Repository name
  • 改为：agentforge

2. 更新描述：

⚔️ Forge your AI agents like legendary heroes - RPG-style builder for Claude agents | AI Agent 可视化构建工具

3. 添加 Topics：

ai-agents, claude, rpg, task-management, electron, typescript, agent-builder
