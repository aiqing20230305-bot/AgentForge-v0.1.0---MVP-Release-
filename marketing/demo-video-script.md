## Recording Best Practices

### Preparation
1. **Clean environment:** Close unnecessary apps, hide desktop icons
2. **Disable notifications:** Turn off Slack, email, messages
3. **Audio test:** Record 30s, playback to check quality
4. **Script practice:** Read through 2-3 times before recording
5. **Water nearby:** Stay hydrated, avoid mouth clicks

### During Recording
1. **Speak clearly:** Slightly slower than normal conversation
2. **Pause generously:** Makes editing easier
3. **Restart mistakes:** Don't try to continue, just restart the sentence
4. **Energy level:** Maintain enthusiasm, smile while talking
5. **Mouse movements:** Slow, deliberate - fast movements look jerky

### Post-Production
1. **Cut aggressively:** Remove all ums, ahs, pauses > 2s
2. **Add music:** 20-30% volume, fade in/out
3. **Color grading:** Vibrant, punchy (increase saturation 10-15%)
4. **Captions:** Auto-generate with YouTube/B站, then manually fix errors
5. **Thumbnail:** High contrast, large text, human face (if possible)

## GIF Creation for Social Media

### Tools
- **Screen recording:** QuickTime (Mac) or OBS (cross-platform)
- **Video → GIF:** ezgif.com (online, free)
- **Optimization:** gifsicle (command-line tool)

### Specifications
- **Resolution:** 800x600 or 1000x750 (smaller than video)
- **Frame rate:** 15-20fps (not 60fps, file too large)
- **Duration:** 5-10 seconds (looping)
- **File size:** < 5MB for Twitter, < 10MB for Reddit
- **Optimization:** Lossy 80, scale colors to 128

### Suggested GIF Clips
1. **Heartbeat pulsing** - Agent card with vitality animation (5s loop)
2. **Evolution trigger** - Notification popup with confetti (8s)
3. **Vitality predictor** - Graph showing 24h forecast (6s)
4. **Full dashboard** - Pan across all agents (10s)

### Conversion Command
```bash
# Record video with QuickTime
# Then convert to GIF:

ffmpeg -i input.mov -vf "fps=15,scale=800:-1:flags=lanczos" -c:v gif output.gif

# Optimize with gifsicle
gifsicle -O3 --lossy=80 --colors 128 output.gif -o optimized.gif
```
