## 🚀 Getting Started

### Step 1: Set Up Development Environment

```bash
# Install AgentForge CLI
npm install -g @agentforge/cli

# Create new plugin from template
agentforge create-plugin my-awesome-plugin

# Navigate to plugin directory
cd my-awesome-plugin

# Install dependencies
npm install

# Start development server
npm run dev
```

### Step 2: Build Your Plugin

```typescript
// src/index.ts
import { Plugin, PluginContext } from '@agentforge/sdk';

export default class MyPlugin extends Plugin {
  name = 'my-awesome-plugin';
  version = '1.0.0';

  async initialize(context: PluginContext) {
    // Plugin initialization logic
  }

  async execute(action: string, params: any) {
    // Plugin action logic
  }
}
```

### Step 3: Test Your Plugin

```bash
# Run unit tests
npm test

# Test with example agent
npm run test:agent

# Lint and format
npm run lint
```

### Step 4: Submit

1. Push to GitHub
2. Create release tag (v1.0.0)
3. Record demo video
4. Fill out submission form
5. Submit before deadline!

## ❓ FAQ

### Q: Can I submit a plugin I've already built?
A: Yes, but it must be significantly updated during the contest period with new features or improvements.

### Q: Can I work on a plugin as part of a team?
A: Absolutely! Teams of up to 4 members are welcome. Prize money will be split among team members.

### Q: What if my plugin requires paid API keys?
A: That's fine. Provide test credentials or mock data for judges. Document clearly what users need to set up.

### Q: Can I use AI tools to help build my plugin?
A: Yes! GitHub Copilot, ChatGPT, etc. are all fair game. Just ensure you understand and can explain all code.

### Q: What happens to my plugin after the contest?
A: You retain all rights. We hope you'll publish to our marketplace, but it's optional.

### Q: Can I submit in multiple categories?
A: One submission per plugin, but you can submit different plugins in different categories.

### Q: What if I miss the deadline by a few hours?
A: Sorry, no extensions. We recommend submitting early to avoid last-minute issues.

### Q: Do I need to be present at the winner announcement?
A: Not required, but strongly encouraged! It's a great networking opportunity.
