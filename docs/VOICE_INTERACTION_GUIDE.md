# AgentForge 语音交互使用指南

## 概述

AgentForge 集成了完整的语音交互系统，支持语音播报（TTS）和语音命令（Speech Recognition）功能，让你可以通过语音控制应用和接收任务通知。

## 快速开始

### 1. 启用语音功能

1. 点击右下角的紫色麦克风按钮
2. 首次使用时，浏览器会请求麦克风权限，点击"允许"
3. 或者：打开设置 → 语音标签页，启用相关功能

### 2. 测试语音播报

1. 打开设置 → 语音
2. 确保"启用语音播报"开关已打开
3. 点击"测试语音"按钮
4. 你应该能听到语音播报

### 3. 尝试语音命令

1. 点击右下角的麦克风按钮（或右键打开菜单）
2. 按钮变为红色并开始脉冲，表示正在监听
3. 清晰地说出命令，例如："显示统计"
4. 系统会识别命令并执行相应操作

## 支持的语音命令

| 命令（中文） | 命令（英文） | 功能说明 |
|-------------|-------------|---------|
| 创建任务 | Create Task | 打开创建任务对话框 |
| 暂停所有 | Pause All | 暂停所有进行中的任务 |
| 显示统计 | Show Stats | 播报任务统计数据 |
| 打开设置 | Open Settings | 打开设置面板 |
| 查看任务 | View Tasks | 显示任务列表并播报 |
| 开始任务 | Start Task | 开始第一个待处理任务 |
| 完成任务 | Complete Task | 完成当前进行中的任务 |

### 命令变体

每个命令支持多种说法，例如：
- "创建任务" 也可以说成 "新建任务"、"添加任务"
- "暂停所有" 也可以说成 "停止所有"、"全部暂停"
- "显示统计" 也可以说成 "查看统计"、"统计数据"

## 语音设置详解

### TTS（语音播报）设置

#### 语言
- **中文**：使用中文语音播报
- **English**：使用英文语音播报

#### 语音选择
系统会自动检测可用的语音列表。不同操作系统提供的语音数量和质量有所不同：
- **Windows**: 通常有多个高质量中英文语音
- **macOS**: 提供 Siri 语音和其他系统语音
- **Linux**: 取决于安装的 TTS 引擎

#### 语速（Rate）
- **范围**: 0.5x - 2.0x
- **默认**: 1.0x
- **建议**:
  - 学习场景：0.7x - 0.9x
  - 正常使用：1.0x - 1.2x
  - 快速浏览：1.3x - 1.5x

#### 音调（Pitch）
- **范围**: 0.5 - 2.0
- **默认**: 1.0
- **效果**:
  - < 1.0：更低沉的声音
  - = 1.0：自然音调
  - > 1.0：更高亢的声音

#### 音量（Volume）
- **范围**: 0% - 100%
- **默认**: 100%
- **提示**: 建议配合系统音量一起调节

### 语音识别设置

#### 启用语音命令
主开关，控制是否允许使用语音命令。

#### 持续识别
- **开启**: 命令执行后自动重新开始监听，无需手动点击
- **关闭**: 每次识别后需要手动点击按钮重新开始
- **建议**: 频繁使用时开启，偶尔使用时关闭

#### 降噪处理
- **功能**: 减少背景噪音干扰
- **建议**:
  - 安静环境：可关闭
  - 嘈杂环境：建议开启

#### 回声消除
- **功能**: 消除扬声器播放声音导致的回声
- **建议**:
  - 使用耳机：可关闭
  - 使用扬声器：建议开启

## 最佳实践

### 1. 语音命令技巧
- 📢 **清晰发音**：确保每个字都清晰
- 🎤 **适当距离**：距离麦克风 20-50cm
- 🔇 **安静环境**：减少背景噪音
- ⏱️ **适当语速**：不要太快或太慢
- 🗣️ **标准发音**：使用普通话或标准英语

### 2. 环境优化
- 使用降噪耳麦效果最佳
- 避免在空旷房间使用（回声大）
- 关闭不必要的背景音乐或视频
- 风扇、空调等持续噪音会影响识别

### 3. 浏览器选择
- ✅ **推荐**: Chrome、Edge
- ⚠️ **部分支持**: Safari (TTS正常，识别受限)
- ❌ **不支持**: Firefox (仅TTS)

### 4. 权限管理
- 允许浏览器访问麦克风
- 在浏览器设置中管理麦克风权限
- 某些网站可能需要 HTTPS 才能使用麦克风

## 隐私说明

### 数据处理
- ✅ 所有语音识别**完全在浏览器本地**进行
- ✅ **不会上传**任何语音数据到服务器
- ✅ 识别结果仅用于执行命令，**不存储**
- ✅ 使用浏览器原生 Web Speech API

### 权限控制
- 麦克风权限由**浏览器**控制
- 可随时在浏览器设置中**撤销**权限
- 不使用时，建议**关闭语音识别**功能

## 故障排除

### 问题 1：没有声音
**可能原因**:
- 系统音量或浏览器音量静音
- 语音播报功能未启用
- 选择的语音不可用

**解决方案**:
1. 检查系统和浏览器音量
2. 打开设置 → 语音，确认"启用语音播报"已开启
3. 尝试选择不同的语音
4. 点击"测试语音"按钮验证

### 问题 2：语音识别不工作
**可能原因**:
- 浏览器不支持（如 Firefox）
- 麦克风权限被拒绝
- 麦克风硬件问题

**解决方案**:
1. 使用 Chrome 或 Edge 浏览器
2. 检查浏览器地址栏左侧的权限图标
3. 在系统设置中确认麦克风可用
4. 尝试其他应用测试麦克风

### 问题 3：识别率低
**可能原因**:
- 背景噪音过大
- 发音不清晰
- 麦克风质量差
- 距离麦克风太远或太近

**解决方案**:
1. 开启降噪和回声消除
2. 清晰、缓慢地说出命令
3. 使用更好的麦克风设备
4. 调整与麦克风的距离

### 问题 4：命令识别错误
**可能原因**:
- 方言或口音较重
- 环境噪音干扰
- 命令说法不标准

**解决方案**:
1. 尽量使用普通话或标准英语
2. 参考支持的命令列表，使用标准说法
3. 在安静环境中使用
4. 查看实时识别结果，了解系统如何理解你的话

## 高级功能

### 自定义语音命令（开发者）

```typescript
import { voiceService } from '@/services/voiceService'

// 注册自定义命令
voiceService.registerCommand({
  command: '打开面板',
  patterns: [
    /打开.*面板/i,
    /显示.*面板/i,
    /open.*panel/i
  ],
  handler: () => {
    // 执行操作
    openPanel()
  },
  description: '打开指定面板'
})
```

### 编程式语音播报

```typescript
import { voiceService } from '@/services/voiceService'

// 简单播报
voiceService.speak('操作完成')

// 自定义语音
voiceService.speak('这是一条重要通知', {
  rate: 0.9,    // 稍慢速度
  pitch: 1.1,   // 稍高音调
  volume: 1.0   // 最大音量
})

// 任务完成通知
voiceService.notifyTaskComplete('数据导出任务')

// 错误提示
voiceService.notifyError('网络连接失败')

// Agent 状态播报
voiceService.notifyAgentStatus('ATLAS', '正在执行任务')

// 统计播报
voiceService.notifyStats({
  total: 50,
  completed: 35,
  pending: 15
})
```

## 技术规格

### 支持的浏览器
| 浏览器 | TTS | 语音识别 | 备注 |
|--------|-----|----------|------|
| Chrome | ✅ | ✅ | 完全支持 |
| Edge | ✅ | ✅ | 完全支持 |
| Safari | ✅ | ⚠️ | 识别功能受限 |
| Firefox | ✅ | ❌ | 不支持识别 |

### API 依赖
- **TTS**: Web Speech API - SpeechSynthesis
- **识别**: Web Speech API - SpeechRecognition
- **存储**: localStorage（设置持久化）

### 性能指标
- TTS 响应时间: < 100ms
- 识别响应时间: < 500ms
- 内存占用: < 5MB
- CPU 占用: 忽略不计（浏览器原生）
