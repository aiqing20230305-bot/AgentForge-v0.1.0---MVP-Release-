# Screenshots Directory

This directory contains product screenshots and demo GIFs for AgentForge.

## 📋 Required Files

Please add the following files to this directory:

### Screenshots (PNG, 1920x1080)
- `screenshot-main.png` - Main interface with agent panel
- `screenshot-tasks.png` - Task management interface
- `screenshot-discovery.png` - Data source configuration
- `screenshot-equipment.png` - RPG equipment system

### Demo GIFs (< 5MB each)
- `demo.gif` - 5 second quick demo
- `task-management.gif` - 10 second task flow
- `auto-discovery.gif` - 8 second auto-discovery

## 📸 How to Capture

1. Run the application: `npm run dev`
2. Navigate to the desired screen
3. Use screenshot tool (Cmd+Shift+4 on macOS)
4. Save files to this directory
5. Optimize images to reduce file size

See `/docs/SCREENSHOTS.md` for detailed instructions.
