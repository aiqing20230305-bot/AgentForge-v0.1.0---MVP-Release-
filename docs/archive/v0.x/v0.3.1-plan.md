## 🚀 Planned Features

### 1. QR Code for Invite Codes ⭐ (High Priority)
**Why:** Makes mobile sharing super easy
**Effort:** 30 minutes
**Impact:** High

**Implementation:**
```typescript
// src/utils/qrcode.ts
import QRCode from 'qrcode'

export async function generateInviteQRCode(
  code: string,
  baseURL: string = 'https://agentforge.app'
): Promise<string> {
  const url = `${baseURL}?invite=${code}`
  try {
    const qrCodeDataURL = await QRCode.toDataURL(url, {
      width: 256,
      margin: 2,
      color: {
        dark: '#06b6d4',  // Cyan theme color
        light: '#0a0a0a'   // Dark background
      }
    })
    return qrCodeDataURL
  } catch (error) {
    console.error('QR Code generation failed:', error)
    throw error
  }
}
```

**Usage in InvitePanel:**
- Show QR code modal when clicking "Show QR" button
- One-click download QR code image
- Mobile-optimized display

### 3. Settings Persistence Enhancement 🔧 (Medium Priority)
**Why:** Users want their preferences saved
**Effort:** 30 minutes
**Impact:** Medium

**Current State:**
- Audio settings: ✅ Saved in LocalStorage
- Theme preference: ❌ Not saved
- Panel layout: ❌ Not saved
- Notification settings: ❌ Not saved

**Implementation:**
```typescript
// src/store/useSettingsStore.ts (new)
interface UserSettings {
  theme: 'dark' | 'light' | 'auto'
  audioEnabled: boolean
  audioVolume: number
  sfxVolume: number
  notificationsEnabled: boolean
  desktopNotifications: boolean
  dailyQuestAutoShow: boolean
  expBarVisible: boolean
  panelLayout: 'default' | 'compact' | 'expanded'
}

export const useSettingsStore = create<SettingsStore>()(
  persist(
    (set) => ({
      settings: DEFAULT_SETTINGS,
      updateSettings: (updates) => set(state => ({
        settings: { ...state.settings, ...updates }
      }))
    }),
    {
      name: 'agentforge-settings'
    }
  )
)
```
