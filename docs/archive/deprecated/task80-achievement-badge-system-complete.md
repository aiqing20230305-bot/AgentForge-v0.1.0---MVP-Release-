#### 华丽的视觉设计
- **渐变背景** - 从灰黑渐变，带有动态装饰元素

- **总进度卡片** - 显示已解锁/总数，带动画进度条
- **稀有度统计** - 4个卡片（普通、稀有、史诗、传说）
  - 点击可筛选对应稀有度的成就
  - 带高亮边框和发光效果
- **特殊统计**
  - 隐藏成就解锁数量

### 2. 3D徽章效果

#### 视觉层次
- **3D变换** - 使用 `transform-style: preserve-3d` 和 `perspective`
- **悬停效果** - 鼠标悬停时徽章放大、上浮、轻微旋转
- **光泽层** - 从左上到右下的白色渐变遮罩
- **阴影效果** - 多层阴影创造深度感：
  - `drop-shadow` 用于图标
  - `shadow-*` 用于卡片发光
  - 阴影强度随稀有度递增

#### 稀有度配置
```typescript
common (普通): 灰色系 - 10点
rare (稀有): 蓝色系 - 25点
epic (史诗): 紫色系 - 50点
legendary (传说): 橙黄色系 - 100点
```

每个稀有度有独特的：
- 渐变色（3色渐变）
- 边框颜色
- 发光强度
- 3D阴影深度
- 表情符号标识

### 3. 动画特效

#### 入场动画
- **列表项** - 依次淡入+缩放+上浮（错开延迟）
- **3D旋转** - 已解锁成就的图标持续旋转
- **进度条** - 从0到实际进度的动画填充

#### 交互动画

- **分享按钮** - 旋转+缩放动画

#### 背景装饰
- **渐变球** - 持续旋转和缩放（20-25秒周期）
- **光泽扫过** - 微妙的光线流动效果

## 📊 技术实现细节

### 组件架构
```
AchievementWall (主组件)
├── 统计头部
│   ├── 旋转奖杯
│   ├── 成就点数
│   ├── 总进度卡片
│   ├── 4个稀有度卡片
│   └── 2个特殊统计卡片
├── 排序筛选按钮组
├── 徽章墙网格 (4列)
│   └── 徽章卡片 (带3D效果)
│       ├── 分享按钮
│       ├── 稀有度角标
│       ├── 3D图标
│       ├── 进度条
│       └── 隐藏遮罩 (如适用)
└── 全局排行榜侧边栏

AchievementDetailModal (详情弹窗)
├── 3D图标
├── 稀有度标签
├── 成就名称和描述
├── 进度条
├── 奖励列表
└── 按钮组 (分享+关闭)
```

### 性能优化
- **useMemo** - 缓存过滤和排序结果
- **动画分层** - 关键动画使用transform和opacity
- **错开延迟** - 列表项入场动画错开，避免卡顿
- **条件渲染** - 隐藏成就遮罩、分享按钮等按需渲染

### 响应式设计
- **网格布局** - 4列网格，支持自动换行
- **侧边栏** - 固定宽度，滚动容器
- **模态框** - max-w-[90vw] 防止溢出

### 音效集成
- 点击徽章 - 已解锁播放 'achievement'，未解锁播放 'click'
- 点击筛选/排序 - 播放 'click'
- 分享按钮 - 播放 'click'

### 数据流
```
agent.achievements.unlocked[] → 已解锁列表
agent.achievements.progress{} → 进度数据
ACHIEVEMENTS[] → 成就定义
useLeaderboardStore.getLeaderboard('achievement_points') → 排行榜
```
