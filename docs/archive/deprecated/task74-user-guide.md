# 全局搜索功能 - 用户使用指南

## 🔍 功能概述

全局搜索是 AgentForge 的快速导航工具，支持搜索 Agents、Tasks 和功能，让你无需记住所有功能的位置。

---

## ⌨️ 快捷键

### 打开搜索
- **Mac**: `Cmd + K`
- **Windows/Linux**: `Ctrl + K`

### 导航和选择
- `↑` / `↓` - 上下选择结果
- `Enter` - 确认选择
- `Escape` - 关闭搜索

---

## 🎯 搜索范围

### 1. Agents（装备道具）
搜索你的背包中的所有装备、技能、工具等。

**示例搜索：**
- "角色" - 查找角色类装备
- "技能" - 查找技能类道具
- "claude" - 查找名称包含 claude 的道具

### 2. Tasks（任务）
搜索所有任务，包括进行中、已完成和待办任务。

**示例搜索：**
- "优化" - 查找所有优化相关任务
- "ATLAS" - 查找 ATLAS Agent 的任务
- "bug" - 查找 bug 修复任务

### 3. Features（功能）
搜索系统功能和导航项。

**示例搜索：**
- "设置" - 打开设置页面
- "排行榜" - 查看排行榜
- "成就" - 查看成就系统

---

## 🧠 智能搜索

### 模糊匹配
不需要输入完整的单词，系统会智能匹配：

```
输入: "agt"  →  匹配: "Agent"
输入: "优化"  →  匹配: "性能优化"、"优化系统"
输入: "cls"  →  匹配: "ATLAS"、"class"
```

### 相关度排序
搜索结果按相关度自动排序：
1. **完全匹配** - 100 分
2. **包含匹配** - 80 分
3. **字符顺序匹配** - 60 分

---

## 📜 搜索历史

系统会自动保存你的搜索历史（最多 10 条）。

**使用方式：**
1. 打开搜索（Cmd+K）
2. 不输入任何内容
3. 查看底部的"最近搜索"
4. 点击历史记录快速重新搜索

---

```
Cmd+K  →  输入关键词  →  ↓↓  →  Enter
```

## 🚀 高级用法

### 1. 连续搜索
不关闭搜索框，可以连续搜索多个内容：
```
搜索 "agent" → 看结果 → 清空 → 搜索 "task"
```

### 2. 历史记录管理
- 自动去重 - 相同搜索不会重复记录
- 最多 10 条 - 超过自动删除最旧的
- 持久化保存 - 关闭应用后依然存在

### 3. 快速切换
搜索后不满意？按 Escape 关闭，重新搜索：
```
Cmd+K → 搜索 → Escape → Cmd+K → 重新搜索
```

## ⚠️ 注意事项

### 搜索不到内容？
1. **检查拼写** - 确保关键词正确
2. **简化关键词** - 输入更短的词（如 "优化" 而非 "性能优化系统"）
3. **使用模糊搜索** - 输入部分字符即可

### 快捷键不生效？
1. **检查输入焦点** - 确保不在其他输入框中
2. **检查系统快捷键** - 部分系统可能占用 Cmd+K
3. **尝试刷新页面** - 有时需要重新加载

### 性能问题？
1. **搜索防抖** - 系统会等待你输入完毕（150ms）
2. **结果限制** - 最多显示前 100 个结果
3. **清理历史** - 可以手动清空搜索历史

## 🆘 常见问题（FAQ）

### Q1: 搜索结果太多，如何筛选？
**A:** 输入更具体的关键词，或使用完整词语。例如：
- "优化" → 10+ 结果
- "性能优化" → 3 个结果

### Q2: 可以同时搜索多个关键词吗？
**A:** 暂不支持，但可以输入最核心的关键词。未来版本会支持高级搜索。

### Q3: 搜索历史可以清空吗？
**A:** 可以！在搜索历史区域点击"清空"按钮。

### Q4: 支持中文拼音搜索吗？
**A:** 当前版本暂不支持，但已在规划中（v1.3.1）。

### Q5: 可以搜索历史任务吗？
**A:** 可以！所有任务（包括已完成的）都会被搜索。
