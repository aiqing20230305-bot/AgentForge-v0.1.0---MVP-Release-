## 🎮 上瘾机制设计

### 核心循环（Core Loop）
```
操作 → 即时反馈 → 进度可见 → 奖励 → 下一个目标
  ↑                                      ↓
  └──────────── 持续动力 ←───────────────┘
```

### 八角行为分析框架

#### 1. 史诗意义（Epic Meaning）
- "你是全球前1%的效率大师"
- "你的优化帮助节省了1万美元"
- "你是社区贡献者"

#### 2. 成就（Accomplishment）
- 清晰的进度条
- 等级系统
- 成就徽章
- 排行榜

#### 3. 创造力（Creativity）
- 自定义Agent配置
- 技能树自由搭配
- 皮肤自定义
- 战斗策略

#### 4. 拥有感（Ownership）
- Agent是"你的"
- 成就收集
- 稀有物品
- 个人品牌

#### 5. 社交影响（Social Influence）
- 排行榜竞争
- 好友系统
- 炫耀机制
- 邀请奖励

#### 6. 稀缺性（Scarcity）
- 限时活动
- 稀有成就
- 限量皮肤
- 倒计时

#### 7. 未知性（Unpredictability）
- 随机奖励
- 抽卡系统
- 战斗结果
- 每日任务变化

#### 8. 损失规避（Loss Aversion）
- 连续登录奖励
