## 🐛 问题修复记录

### TypeScript编译错误修复

**问题1：** AgentData类型路径错误
- ❌ `import { AgentData } from '../types/agent'`
- ✅ `import { AgentData } from '../store/useDataSourceStore'`

**问题2：** useDataSourceStore API不匹配
- ❌ `dataSource` 属性不存在
- ✅ 使用 `activeSourceId` 和 `sources`
- ❌ `setDataSource()` 方法不存在
- ✅ 使用 `setActiveSource()`
- ❌ `agents` 属性不存在
- ✅ 使用 `agentsCache`

**问题3：** AgentData字段不匹配
- ❌ 使用了不存在的字段（heartRate, vitalityScore等）
- ✅ 只使用Store定义的标准字段

**问题4：** 状态映射错误
- ❌ `'active'` 不是有效的status值
- ✅ 使用 `'online' | 'offline' | 'working' | 'idle' | 'unknown'`

**结果：** ✅ 所有OpenClaw相关文件TypeScript检查通过
