## ⚠️ 已知问题和解决方案

### 问题 #1: Agent数据缺少扩展字段

**症状：** 技能树、成就面板显示空白

**原因：** Agent数据缺少：
```typescript
{
  skillTree?: {
    unlockedSkills: string[]
    skillPoints: number
    skillLevels: Record<string, number>
  }
  achievements?: {
    unlocked: string[]
    progress: Record<string, number>
  }
  levelSystem?: {
    currentLevel: number
    currentExp: number
    ...
  }
}
```

**解决方案：**
```typescript
// 在 useDataSourceStore 的初始化中添加默认数据
export function initializeDefaultDataSources() {
  const agents = get().agentsCache
  agents.forEach(agent => {
    if (!agent.skillTree) {
      agent.skillTree = {
        unlockedSkills: [],
        activeSkills: [],
        skillPoints: 5, // 给新用户5个技能点
        skillLevels: {}
      }
    }
    if (!agent.achievements) {
      agent.achievements = {
        unlocked: [],
        progress: {}
      }
    }
    if (!agent.levelSystem) {
      agent.levelSystem = {
        currentLevel: agent.level || 1,
        currentExp: agent.exp || 0,
        expToNextLevel: 100,
        totalExp: agent.exp || 0,
        prestigeLevel: 0,
        levelHistory: []
      }
    }
  })
}
```

**优先级：** 🔴 **高** - 需要立即修复
