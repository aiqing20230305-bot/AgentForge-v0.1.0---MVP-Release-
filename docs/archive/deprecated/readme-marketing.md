## 🔥 What Makes AgentForge Special?

### 🫀 Living, Breathing Agents

Your agents aren't just code - they're **living entities** with health, personality, and evolution.

```typescript
// Every 30 seconds, AgentForge checks 6 vitality factors:
vitality = calculate([
  task_completion_rate,  // 40% weight
  error_rate,            // 20% weight
  avg_response_time,     // 15% weight
  resource_usage,        // 10% weight
  last_active_time,      // 10% weight
  health_trend          // 5% weight
]) // Result: 0-100 score
```

**Real-Time Monitoring**:
- 🫀 30-second heartbeat intervals
- 📊 6-factor vitality scoring
- 🚦 4-level health status (Healthy → Critical)
- ⚠️ Proactive warnings before failures
- 🎁 Auto-rewards for healthy agents

### 🔮 Predictive Analytics

**Forecast agent health up to 24 hours ahead** using linear regression.

```typescript
prediction = forecast({
  timeframe: '24h',

  trend: 'declining'
```

## 🚀 Quick Start (5 Minutes)

### Option 1: npm (Development)

```bash
# Clone repo
git clone https://github.com/aiqing20230305-bot/AgentForge-v0.1.0---MVP-Release-.git
cd AgentForge-v0.1.0---MVP-Release-

# Install dependencies
npm install

# Start dev server
npm run dev
```

Open http://localhost:5173 🎉

---

### Option 2: Docker (Production)

```bash
# Pull image
docker pull agentforge/agentforge:latest

# Run container
docker run -p 5173:5173 agentforge/agentforge:latest
```

Open http://localhost:5173 🎉

---

### Option 3: Desktop App (Easiest)

**Download for your platform**:

- 🍎 [**macOS**](link) - DMG installer (Intel & Apple Silicon)
- 🪟 [**Windows**](link) - EXE installer (x64 & x86)
- 🐧 [**Linux**](link) - AppImage, DEB, RPM

Double-click to install. Launch. Done! 🎉
