# AI 助手功能文档

## 概述

AI助手是AgentForge的智能优化模块，提供任务管理建议、性能分析和工作流优化。

## 功能特性

### 1. 智能建议系统

#### 任务优先级推荐
- **高优先级任务积压检测**: 识别等待超过3天的高优先级任务
- **紧急任务过多预警**: 当紧急任务超过5个时提醒重新评估
- **低优先级任务积累**: 建议批量处理低优先级任务

#### 技能升级建议
- **失败率分析**: 识别失败率超过30%的技能领域
- **核心技能加强**: 基于高频任务标签推荐深化学习
- **学习路径规划**: 根据任务模式推荐技能提升方向

#### 资源分配优化
- **负载均衡检测**: 识别过载和低载的Agent
- **任务重新分配建议**: 提供具体的任务转移方案
- **资源使用效率分析**: 优化Agent工作分配

#### 性能问题诊断
- **任务失败率监控**: 失败率超过20%时发出警告
- **执行时间分析**: 识别耗时过长的任务
- **卡死任务检测**: 发现运行超过24小时的任务

#### 工作流优化
- **任务创建模式分析**: 识别高峰时段
- **批量处理建议**: 推荐相似任务的批处理方案
- **自动化机会识别**: 发现可自动化的重复任务模式

### 2. 自然语言交互

支持的命令示例：
- "帮我优化任务队列" - 生成优化建议
- "分析性能指标" - 显示详细性能数据
- "给我一些建议" - 展示所有建议
- "查看我的工作习惯" - 分析用户行为模式

### 3. 性能指标仪表板

#### 关键指标
- **任务吞吐量**: 每天完成的任务数量
- **平均完成时间**: 任务平均执行时长（小时）
- **失败率**: 任务失败百分比
- **瓶颈识别**: 自动检测性能瓶颈

#### 用户习惯分析
- **高效工作时段**: 识别最佳工作时间
- **任务完成率**: 按优先级统计完成率
- **常用标签**: 最频繁使用的任务标签
- **Agent负载分布**: 各Agent的任务分配情况

### 4. 学习用户习惯

系统会自动分析并学习：
- 任务创建和完成的时间模式
- 不同优先级任务的处理效率
- 常用的任务标签和分类
- Agent的工作负载分布

学习结果用于生成更精准的建议。

## 使用指南

### 启动AI助手

1. 在主界面点击 "AI助手" 标签
2. 系统会自动分析当前任务数据
3. 查看生成的智能建议

### 查看建议

1. 切换到 "建议" 标签
2. 浏览按优先级排序的建议列表
3. 每条建议包含：
   - 建议类型和标题
   - 详细描述
   - 影响等级（高/中/低）
   - 置信度（0-100%）
   - 可执行的操作按钮

### 性能监控

1. 切换到 "指标" 标签
2. 查看关键性能指标
3. 检查识别出的瓶颈
4. 分析用户工作习惯

### 自然语言对话

1. 在 "对话" 标签的输入框输入问题
2. 使用快捷按钮快速发送常用命令
3. AI助手会分析并给出回答
4. 查看历史对话记录

## 技术实现

提供以下核心功能：

```typescript
// 生成智能建议
await aiAssistant.generateSuggestions(tasks, agentId?)

// 获取性能指标
const metrics = aiAssistant.getPerformanceMetrics(tasks)

// 解析自然语言命令
const result = await aiAssistant.parseCommand(command, tasks)

// 获取用户习惯
const habits = aiAssistant.getUserHabits()
```

### UI组件: `AIAssistantPanel.tsx`

- 三标签界面：对话、建议、指标
- 实时消息流
- 响应式建议列表
- 性能数据可视化

## 建议类型说明

### task_priority (任务优先级)
- 分析任务队列中的优先级问题
- 识别积压和不合理的优先级设置
- 建议重新评估和调整

### skill_upgrade (技能升级)
- 基于任务失败率识别技能缺口
- 推荐学习方向
- 提供技能提升建议

### resource_allocation (资源分配)
- 分析Agent负载
- 建议任务重新分配
- 优化资源利用率

### performance_diagnosis (性能诊断)
- 诊断执行问题
- 识别性能瓶颈
- 提供优化方案

### workflow_optimization (工作流优化)
- 发现任务模式
- 推荐批处理策略
- 识别自动化机会

## 影响等级

- **High (高影响)**: 显著影响系统效率，建议立即处理
- **Medium (中影响)**: 有改进空间，建议近期处理
- **Low (低影响)**: 小幅优化，可选择性处理

## 置信度说明

- **90-100%**: 高度确信，基于充分数据
- **70-89%**: 较为确信，建议参考
- **50-69%**: 初步判断，仅供参考
- **<50%**: 不确定，需要更多数据

## 常见问题

**Q: AI助手多久更新一次建议？**
A: 每5分钟自动分析一次，或在任务变化时触发更新。

**Q: 建议会自动执行吗？**
A: 不会。所有建议仅供参考，需要用户手动确认执行。

**Q: 如何提高建议准确性？**
A: 使用更多任务，保持任务元数据完整，系统会随使用时间学习改进。

**Q: 可以关闭某些类型的建议吗？**
A: 当前版本不支持，未来版本会添加建议过滤功能。

## 示例场景

### 场景1: 任务积压优化

用户有20个待处理任务，其中8个高优先级任务已等待超过3天。

**AI助手行为**:
1. 检测到高优先级任务积压
2. 生成建议：立即处理或重新评估优先级
3. 分析负载：检查是否有Agent可以协助
4. 提供具体行动方案

### 场景2: 技能提升建议

某Agent在"前端开发"相关任务中失败率达35%。

**AI助手行为**:
1. 识别高失败率技能领域
2. 生成技能升级建议
3. 推荐学习资源或寻求专家支持
4. 建议将此类任务分配给其他Agent

### 场景3: 工作流自动化

用户每周重复创建类似的"代码审查"任务。

**AI助手行为**:
1. 检测重复任务模式
2. 建议创建自动化工作流
3. 提供批量处理方案
4. 推荐使用模板简化创建流程
