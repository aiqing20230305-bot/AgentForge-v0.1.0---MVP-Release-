# 🎯 AgentForge - 产品定位

## 核心理念

**AgentForge 是一个尊重用户隐私、强调用户主导的 AI Agent 管理平台。**

### 🔐 隐私优先 Privacy-First

AgentForge 的设计哲学是：**用户完全控制数据，系统不主动扫描任何外部服务**。

#### 我们的承诺

- ✅ **不主动匹配** - 不自动扫描或连接 OpenClaw、API 或任何外部服务
- ✅ **需用户授权** - 所有数据源连接均需用户明确告知和配置
- ✅ **透明可控** - 用户随时知道系统在连接什么、访问什么
- ✅ **本地优先** - 核心功能可完全离线使用，无需云端

#### 与传统工具的区别

| 传统 AI 管理工具 | AgentForge |
|-----------------|-----------|
| ❌ 自动扫描系统服务 | ✅ 用户手动配置 |
| ❌ 后台自动连接 API | ✅ 明确授权后才连接 |
| ❌ 默认开启所有功能 | ✅ 按需启用功能 |
| ❌ 数据自动上传云端 | ✅ 本地优先，可选云同步 |

## 🌟 产品特色

### 1. 授权式数据源连接

**不主动扫描，用户告知后才连接**

```
传统方式：
1. 工具自动扫描系统中的 OpenClaw 实例
2. 自动连接并读取数据
3. 用户不知道发生了什么

AgentForge 方式：
1. 用户点击"连接数据源"按钮
2. 用户手动输入 OpenClaw URL 或 API 地址
3. 用户确认授权后，系统才开始连接
4. 连接状态透明可见，用户可随时断开
```

### 2. 本地优先架构

- **核心功能离线可用** - Agent 管理、任务追踪、可视化仪表盘
- **可选云同步** - 用户主动启用后才同步数据
- **数据本地存储** - localStorage + IndexedDB，用户完全控制

### 3. 透明的权限管理

- 每个功能都有清晰的权限说明
- 用户可随时查看和撤销授权
- 所有网络请求都有日志记录

## 🔐 安全设计

### 数据隔离

1. **本地数据 100% 隔离**
   - Agent 配置存储在本地
   - 任务历史保存在浏览器
   - 不会上传到任何服务器（除非用户启用云同步）

2. **外部服务按需连接**
   - OpenClaw 连接需要用户输入 URL
   - API 集成需要用户提供密钥
   - 所有连接都可独立开关

3. **零信任架构**
   - 不预设任何外部服务
   - 不内置任何 API 密钥
   - 不收集任何用户行为数据

### 连接安全

- ✅ HTTPS 强制加密
- ✅ API 密钥本地存储（加密）
- ✅ 敏感数据不记录日志
- ✅ 定期安全审计
