## 🚀 5分钟上手流程

```
下载 → 安装 → 启动 → 选择模板 → 配置 → 训练 → 完成
  ↓       ↓      ↓        ↓         ↓      ↓      ↓
 30s     30s    10s      30s       1m     2m    30s  = 5分钟
```

### 详细步骤

1. **下载安装** (30秒)
   - 访问: [agentforge.ai/download](https://agentforge.ai/download)
   - 选择你的平台: Windows / macOS / Linux
   - 双击安装包，一键安装

2. **首次启动** (10秒)
   - 打开 AgentForge
   - 自动弹出新手引导
   - 点击"开始"

3. **选择模板** (30秒)
   - 客服助手 ⭐ (推荐新手)
   - 内容创作者
   - 代码助手
   - 数据分析师

4. **配置 Agent** (1分钟)
   - 输入名称: "我的客服助手"
   - 添加描述: 简短描述功能
   - 实时预览右侧显示

5. **开始训练** (2分钟)
   - 点击"开始训练"
   - 等待进度条完成
   - 自动保存配置

6. **完成部署** (30秒)
   - 查看完成度评分
   - 选择部署方式
   - 复制代码或链接

## 🔧 故障排除

### 常见问题

#### 1. 无法启动 Agent

**问题**: 点击"运行"后没有反应

**解决方案**:
- ✓ 检查 API Key 是否配置: `设置 → API 配置`
- ✓ 确认网络连接正常
- ✓ 重启 AgentForge
- ✓ 查看错误日志: `帮助 → 查看日志`

#### 2. 训练失败

**问题**: 训练进度卡在某个阶段

**解决方案**:
- ✓ 检查磁盘空间: 至少需要 500MB
- ✓ 关闭其他占用资源的程序
- ✓ 重新开始训练
- ✓ 尝试使用更简单的模板

#### 3. API 调用错误

**问题**: 提示 "API Key 无效" 或 "配额不足"

**解决方案**:
- ✓ 验证 API Key: 访问 [claude.ai/account](https://claude.ai/account)
- ✓ 检查账户余额
- ✓ 确认 API 权限设置
- ✓ 更换为备用 API Key

#### 4. 部署代码不工作

**问题**: 嵌入代码在网站上不显示

**解决方案**:
- ✓ 确认代码放在 `</body>` 标签前
- ✓ 检查浏览器控制台错误
- ✓ 验证 Agent ID 正确
- ✓ 检查网站的 CSP 策略

#### 5. 性能问题

**问题**: 应用运行缓慢

**解决方案**:
- ✓ 清理缓存: `设置 → 高级 → 清理缓存`
- ✓ 减少同时运行的 Agent 数量
- ✓ 关闭不需要的插件
- ✓ 重启应用

## 🎯 快速操作指南

### 创建你的第一个 Agent

```bash
1. 点击 "+" 或 Cmd/Ctrl + N
2. 选择 "客服助手" 模板
3. 输入名称: "我的助手"
4. 点击 "开始训练"
5. 等待完成 ✓
```

### 一键部署到网站

```bash
1. 选择 Agent → 点击 "部署"
2. 选择 "嵌入代码"
3. 复制代码
4. 粘贴到网站 </body> 前
5. 完成！
```

### 生成 API 端点

```bash
1. Agent 详情页 → "API"
2. 复制 API 端点和 Key
3. 在代码中调用:
   POST https://api.agentforge.ai/v1/agents/{id}/chat
   Header: Authorization: Bearer {key}
   Body: { "message": "Hello" }
```

### 分享 Agent

```bash
1. Agent 详情页 → "分享"
2. 选择分享方式:
   - 分享链接
   - 二维码
   - 邀请协作者
3. 设置权限:
   - 只读
   - 可编辑
   - 管理员
```

## 💡 实用技巧

### 提升 Agent 质量

1. **清晰的角色定位**
   ```
   好: "我是专业的技术支持客服，擅长解决产品问题"
   差: "我是客服"
   ```

2. **详细的任务描述**
   ```
   好: "回答关于产品功能、价格、售后的问题，语气友好专业"
   差: "回答问题"
   ```

3. **使用示例对话**
   - 提供 3-5 个典型对话示例
   - 展示期望的回复风格
   - 包含边界情况处理

4. **定期更新知识库**
   - 每周审查对话日志
   - 添加新的 FAQ
   - 优化常见问题回复

### 优化性能

1. **批量操作**
   - 选中多个 Agent: `Cmd/Ctrl + 点击`
   - 批量启动/停止
   - 批量导出/导入

2. **使用模板**
   - 创建自定义模板
   - 保存常用配置
   - 快速复用设置

3. **监控用量**
   - 设置每日预算
   - 启用用量提醒
   - 查看分析报告
