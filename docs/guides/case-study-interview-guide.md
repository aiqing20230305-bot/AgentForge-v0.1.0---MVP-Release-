# 🎙️ AgentForge - 用户案例采访指南

## 📋 文档概览

**目标**: 制作高质量的用户案例视频/访谈，展示真实使用场景和效果
**时长**: 每个案例3-5分钟
**数量**: 计划收集5-10个典型案例
**用途**: 营销推广、社交媒体、官网展示
**版本**: v1.0
**更新日期**: 2026-03-17

---

## 🎯 案例采访目标

### 主要目标

1. **建立信任**: 真实用户故事比任何广告都有说服力
2. **展示价值**: 通过实际使用场景展示产品价值
3. **覆盖场景**: 不同行业、不同规模、不同用例
4. **可复制性**: 让潜在用户看到"我也可以这样用"

### 次要目标

1. **收集反馈**: 了解用户痛点和需求
2. **发现亮点**: 挖掘意想不到的使用场景
3. **社交证明**: 提升品牌可信度
4. **用户激励**: 让被采访用户成为品牌大使

### 采访技巧

#### 1. 营造舒适氛围
```
✅ 做到:
- 微笑和眼神交流
- 积极的肢体语言（点头、前倾）
- 真诚的兴趣和好奇
- 适时的鼓励（"很棒的例子！"）

❌ 避免:
- 打断用户
- 看手机/手表
- 表现不耐烦
- 质疑或反驳
```

#### 2. 提问技巧
```
开放式问题 > 封闭式问题
✅ "你们是如何使用的？"
❌ "你们用了XX功能吗？"

具体化 > 抽象化
✅ "能举个具体例子吗？"
❌ "总体来说效果好吗？"

故事化 > 罗列式
✅ "请描述某天早上..."
❌ "列举一下优点"
```

#### 3. 追问技巧
```
5W1H追问:
- What: "具体是什么？"
- Why: "为什么会这样？"
- When: "什么时候发生的？"
- Where: "在哪个环节？"
- Who: "谁参与了？"
- How: "是怎么做的？"

情感追问:
- "当时的感受是？"
- "团队怎么看？"
- "客户的反应？"

数据追问:
- "能量化一下吗？"
- "有具体数字吗？"
- "对比一下前后"
```

#### 4. 引导技巧
```
当用户回答太短:
"能详细讲讲吗？"
"还有什么想补充的？"

当用户离题:
"这个很有意思，我们先回到..."
"刚才你提到XX，能展开说说吗？"

当用户表达不清:
"我理解您的意思是..., 对吗？"
"换个方式说，是不是..."

当需要故事:
"能给我讲个具体的例子吗？"
"想象你在向朋友描述..."
```

### 剪辑技巧

#### 1. 选择最佳片段
```
优先选择:
✅ 情感真挚的片段
✅ 数据清晰的片段
✅ 故事完整的片段
✅ 有意外惊喜的片段

```

慢节奏段落:
- 故事讲述
