## 🎨 后期制作技术指南

### 剪辑技巧

#### 1. 节奏控制

**快节奏段落** (开场、训练、结尾):
- 镜头时长: 1-3秒
- 切换频率: 高
- 音乐: 节奏感强
- 适用于: 展示多个功能、营造紧迫感

**中节奏段落** (配置、部署):
- 镜头时长: 3-5秒
- 切换频率: 适中
- 音乐: 舒缓流畅
- 适用于: 详细操作演示

**慢节奏段落** (关键信息):
- 镜头时长: 5-8秒
- 切换频率: 低
- 音乐: 轻柔
- 适用于: 重要信息强调

#### 2. 切换技巧

**直切 (Hard Cut)**:
- 使用场景: 同一界面内的操作
- 优点: 干净利落
- 注意: 确保动作连贯

**J-Cut / L-Cut**:
- J-Cut: 音频先于画面出现
  - 用于: 场景切换，保持连贯性
  - 示例: 旁白说"接下来选择模板"，画面还在上一个界面
- L-Cut: 音频延续到下一个画面
  - 用于: 平滑过渡
  - 示例: 点击按钮的音效延续到下一个界面

**过渡效果**:
- Cross Dissolve: 柔和过渡（0.5s）
- Dip to Black/White: 章节分隔（1s）
- Slide/Wipe: 创意过渡（0.3s）
- 不要过度使用：整个视频不超过10次特殊过渡

#### 3. 速度调整

**加速播放**:
- 下载安装: 2x - 3x
- 输入文字: 1.5x - 2x
- 训练过程: 实时播放（不加速）

**慢动作**:
- 点击关键按钮: 0.5x（强调）
- 完成动画: 0.7x（增加仪式感）
- 时长: 1-2秒（不要过长）

#### 4. 层次处理

**Z-axis层次**（从前到后）:
1. 字幕和标注（最前）
2. UI高亮/箭头
3. 产品界面
4. 背景效果（粒子、渐变）

**音频层次**:
1. 旁白（-6dB，最重要）
2. 音效（-12dB，辅助）
3. 音乐（-18dB，背景）

### 调色方案

#### 1. 色彩校正流程

**步骤1: 一级调色（Primary Color Correction）**
- 调整曝光: 确保UI元素清晰可见
- 白平衡: 统一所有镜头色温（6500K）
- 对比度: 适当增强（110%）
- 饱和度: 稍微提升（105%）

**步骤2: 二级调色（Secondary Color Correction）**
- 选择性调整品牌色:
  - 紫色: 提升饱和度10%
  - 黄色（推荐标签）: 提升亮度10%
  - 绿色（成功状态）: 保持鲜艳
- 使用HSL曲线微调

**步骤3: 创意调色（Creative Look）**
- 应用LUT（可选）: 科技感/电影感
- 添加暗角（Vignette）: 边缘-15%亮度
- 高光柔化: 避免过曝
- 阴影提亮: 保持细节

**效果**: 粒子汇聚成Logo

**制作步骤**:
1. 创建合成（3s, 3840x2160, 60fps）

4. 添加Glow效果（发光）
5. 时间轴:
   - 0s-1s: 粒子分散状态
   - 1s-2.5s: 快速聚合

**关键帧设置**:
```
Particle Emitter:
0s: Size Random: 100%, Velocity: 500
1s: Size Random: 0%, Velocity: 0
Opacity: 0% → 100%

Glow:
2.5s: Intensity: 0 → 100
```

  100; // 点亮
} else {
  30; // 未激活
}

### 音频处理详解

#### 1. 旁白处理流程

**第一步: 降噪（iZotope RX）**
```
工具: Spectral De-noise
设置:
- Noise Profile: 选择无人声段落
- Reduction: 8-12 dB
- Smoothing: 5
注意: 不要过度降噪，保留自然感
```

**第二步: 去除杂音**
```
工具: De-click / De-clip / Mouth De-click
- 去除爆破音（P, B, T, K）
- 去除呼吸声（Breath Control）
- 去除口水声（Mouth De-click）
```

**第三步: EQ均衡器**
```
频率调整:
- 80Hz 以下: High-pass Filter（去除低频杂音）
- 200-400Hz: -2dB（减少浑浊感）
- 2-4kHz: +3dB（增强清晰度）
- 8-12kHz: +2dB（增加空气感）
```

**第四步: 压缩器（Compressor）**
```
设置:
- Threshold: -18dB
- Ratio: 3:1
- Attack: 5ms
- Release: 50ms
- Makeup Gain: 自动
目的: 平衡音量，减少动态范围
```

**第五步: 限幅器（Limiter）**
```
设置:
- Ceiling: -1dB（防止削波）
- Release: 100ms
目的: 防止爆音
```

**点击音效**（20+位置）:

**完成音效**:
- 阶段完成: 轻快的"叮"声
- 训练完成: 欢快的和弦进行
- 最终完成: 庆祝音效（烟花、欢呼）

**转场音效**:
- Whoosh（嗖）: 界面切换
- Swoosh（刷）: 滑动过渡
- 时长: 0.3-0.5秒

**环境音效**（可选）:
- 键盘打字声（Scene 4）
- 电脑运行声（Scene 5）
- 音量: 非常低（-24dB），营造氛围

#### 3. 背景音乐选择标准

**风格**:
- 科技感、未来感
- Synthwave / Electronic / Ambient
- 无主旋律或主旋律不突出（避免抢戏）

**节奏**:
- BPM: 100-120（适中）
- 律动感强但不急促

**情绪**:
- 积极向上、充满希望
- 平静但有能量

**推荐曲风**:
- Ambient Electronic（环境电子）
- Corporate Tech（企业科技）
- Inspirational Upbeat（激励向上）

**版权**:
- 使用无版权音乐库:
  - Epidemic Sound
  - Artlist
  - AudioJungle
  - YouTube Audio Library
- 或自行制作（推荐）

#### 4. 混音参数参考

**音轨电平标准**:
```
轨道          | 峰值电平 | 平均电平 | 说明
-------------|---------|---------|-----
旁白         | -3dB    | -6dB    | 最重要
关键音效     | -6dB    | -12dB   | 点击、完成
环境音效     | -18dB   | -24dB   | 背景氛围
背景音乐     | -12dB   | -18dB   | 不抢戏
Master总输出 | -1dB    | -16LUFS | 标准响度
```

**Ducking（自动闪避）设置**:
当旁白出现时，背景音乐自动降低音量
```
Sidechain Compressor:
- Input: 旁白轨道
- Output: 音乐轨道
- Threshold: -30dB
- Ratio: 4:1
- Attack: 10ms（快速降低）
- Release: 500ms（缓慢恢复）
- Reduction: 6-10dB
```

**空间感处理**:
```
混响（Reverb）:
- 旁白: Room Reverb, Mix 5%（轻微空间感）
- 音效: 根据场景选择
- 音乐: 不添加（已有制作混响）

立体声宽度:
- 旁白: 中央（0%）
- 音效: 适当平移（±20%）
- 音乐: 宽立体声（100%）
```

#### 2. 字幕时间轴规则

**同步精度**:
- 开始时间: 与旁白同步（±0.1s）
- 结束时间: 延后0.2s（给读者反应时间）

**最短/最长时长**:
- 最短: 1.5s（即使只有2个字）
- 最长: 7s（超过则分句）

**换行规则**:
- 按语义分割（不拆散词组）
- 第一行略短，第二行略长（视觉平衡）

**场景切换处理**:
- 如果字幕跨场景，在切换点断开
- 重新显示完整句子

#### 3. 关键词高亮

**高亮对象**:
- 时间数字: "5分钟"、"30秒"
- 功能数量: "4种模板"、"5个阶段"

- Premiere Pro: 使用Legacy Title创建
