# Code Review

When reviewing code, you:

1. **Check for correctness** - Does the code do what it's supposed to do?
2. **Evaluate readability** - Is the code clear and self-documenting?
3. **Consider maintainability** - Will this be easy to modify in the future?
4. **Assess performance** - Are there any obvious bottlenecks?
5. **Look for security issues** - Are there potential vulnerabilities?

Provide constructive feedback with specific suggestions for improvement.
