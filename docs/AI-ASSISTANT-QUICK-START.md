# AI助手快速开始指南

## 快速上手

### 1. 打开AI助手

在AgentForge主界面，点击顶部导航栏的 **"AI助手"** 标签（带有脑图标🧠）。

### 2. 三种使用方式

#### 方式1: 自然语言对话（推荐新手）

1. 停留在 **"对话"** 标签
2. 在底部输入框输入你的问题
3. 点击发送按钮或按Enter键

**常用命令示例**:
```
帮我优化任务队列
分析当前性能
有什么建议吗
查看我的工作习惯
```

**快捷按钮**:
- "优化任务队列" - 一键获取优化建议
- "分析性能" - 查看性能指标
- "工作习惯" - 了解你的工作模式

#### 方式2: 查看智能建议（推荐老手）

1. 切换到 **"建议"** 标签
2. 浏览AI自动生成的建议列表
3. 根据影响等级和置信度选择执行

**建议类型**:
- 🎯 任务优先级 - 优化任务排序
- 📈 技能升级 - 提升能力短板
- ⚖️ 资源分配 - 平衡工作负载
- ⚠️ 性能诊断 - 发现系统问题
- ⚡ 工作流优化 - 提高效率

#### 方式3: 监控性能指标（推荐管理者）

1. 切换到 **"指标"** 标签
2. 查看4项关键指标
3. 关注瓶颈和异常

**关键指标**:
- 任务吞吐量 - 每天完成多少任务
- 平均完成时间 - 任务平均耗时
- 失败率 - 任务失败百分比
- 瓶颈识别 - 性能问题定位

## 5分钟入门场景

### 场景1: "我的任务太多了，该先做什么？"

**步骤**:
1. 打开AI助手
2. 在对话框输入: "帮我优化任务队列"
3. AI会分析你的任务，给出优先级建议
4. 切换到"建议"标签查看详细建议
5. 根据建议调整任务顺序

**示例输出**:
```
已分析任务队列，发现 2 个高影响建议：
- 高优先级任务积压
- 紧急任务过多
```

### 场景2: "为什么我的任务总是失败？"

**步骤**:
1. 切换到"指标"标签
2. 查看失败率指标
3. 如果失败率>20%，AI会自动生成诊断建议
4. 查看"建议"标签中的"性能诊断"类型
5. 根据建议改进

**可能原因**:
- 任务定义不清晰
- 资源配置不足
- 技能不匹配
- 执行流程有问题

### 场景3: "我想了解我的工作效率"

**步骤**:
1. 在对话框输入: "查看我的工作习惯"
2. AI会显示你的工作模式统计
3. 切换到"指标"标签查看详细数据
4. 找到你的高效时段
5. 在高效时段安排重要任务

**统计内容**:
- 最佳工作时段
- 各优先级完成率
- 常用任务类型
- Agent负载分布

## 实用技巧

### 技巧1: 善用建议过滤

建议按**影响等级**和**置信度**排序：
- **高影响 + 高置信度** = 立即执行
- **高影响 + 中置信度** = 优先考虑
- **中影响 + 高置信度** = 近期处理
- **低影响** = 有空再说

### 技巧2: 定期查看指标

建议每天或每周查看一次指标标签：
- **每日**: 快速查看失败率和吞吐量
- **每周**: 深入分析趋势和瓶颈
- **每月**: 回顾习惯变化，调整策略

### 技巧3: 结合建议调整工作

1. 早上查看AI建议，规划一天工作
2. 午休查看性能指标，调整下午计划
3. 晚上总结，让AI学习你的习惯
4. 周末回顾，制定下周优化方案

### 技巧4: 理解置信度

- **90-100%**: 高度确信，基于大量数据
- **70-89%**: 较为确信，建议采纳
- **50-69%**: 初步判断，谨慎参考
- **<50%**: 数据不足，仅供参考

### 技巧5: 关注建议趋势

- 如果同一建议**连续出现3次**，说明问题严重
- 如果建议**类型集中**，说明该领域需要重点关注
- 如果建议**数量突增**，说明系统状态恶化

## 常见问题

### Q1: AI助手多久更新一次？
**A**: 每5分钟自动分析，或在任务变化时立即更新。

### Q2: 建议会自动执行吗？
**A**: 不会。所有建议仅供参考，需要你手动确认执行。

### Q3: 如何让建议更准确？
**A**:
- 完善任务信息（标题、描述、标签）
- 及时更新任务状态
- 使用更多任务让AI学习
- 保持任务数据质量

### Q4: 可以关闭某些建议吗？
**A**: 当前版本不支持，但你可以忽略不感兴趣的建议。未来版本会添加过滤功能。

### Q5: AI助手会学习我的习惯吗？
**A**: 会。AI会分析你的工作时间、完成率、常用标签等，持续优化建议质量。

### Q6: 数据安全吗？
**A**: 所有分析都在本地进行，不会上传任何数据到服务器（除非你主动开启云同步）。

### 自定义命令

虽然AI支持自然语言，但以下命令响应更快：

| 命令 | 效果 |
|------|------|
| 优化任务队列 | 分析并生成优化建议 |
| 分析性能 | 显示性能指标详情 |
| 查看建议 | 列出所有建议 |
| 工作习惯 | 展示习惯统计 |
| 帮助 | 显示可用命令 |

### 理解建议类型

#### 🎯 任务优先级 (task_priority)
**触发条件**:
- 高优先级任务等待>3天
- 紧急任务>5个
- 低优先级任务>10个

**行动建议**:
- 重新评估优先级
- 分配更多资源
- 设置专门处理时间

#### 📈 技能升级 (skill_upgrade)
**触发条件**:
- 某技能失败率>30%
- 重复类型任务失败
- 缺乏关键技能

**行动建议**:
- 投入学习时间
- 寻求专家支持
- 调整任务分配

#### ⚖️ 资源分配 (resource_allocation)
**触发条件**:
- Agent负载不均
- 任务积压严重
- 资源闲置浪费

**行动建议**:
- 重新分配任务
- 调整Agent数量
- 优化工作分配

#### ⚠️ 性能诊断 (performance_diagnosis)
**触发条件**:
- 失败率>20%
- 执行时间异常
- 任务卡死(>24h)

**行动建议**:
- 检查系统配置
- 优化执行流程
- 重启卡死任务

#### ⚡ 工作流优化 (workflow_optimization)
**触发条件**:
- 相似任务≥5个
- 重复任务模式
- 效率提升空间

**行动建议**:
- 批量处理
- 创建自动化
- 使用任务模板

## 最佳实践

- 优先处理高影响高置信度建议

- 忽略所有建议
