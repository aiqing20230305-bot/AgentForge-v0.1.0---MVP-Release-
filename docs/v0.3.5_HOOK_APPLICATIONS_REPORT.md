## 💡 最佳实践示例

### 1. 搜索优化
```typescript
// ✅ 正确：使用 useDebounce
const [query, setQuery] = useState('')
const debouncedQuery = useDebounce(query, 300)

useEffect(() => {
  searchAPI(debouncedQuery)
}, [debouncedQuery])

// ❌ 错误：直接搜索
onChange={(e) => searchAPI(e.target.value)}
```

### 2. 复制功能
```typescript
// ✅ 正确：使用 useCopy
const [copy, copied] = useCopy()

<button onClick={() => copy(text)}>
  {copied ? '已复制' : '复制'}
</button>

// ❌ 错误：手动实现
navigator.clipboard.writeText(text)
setCopied(true)
setTimeout(() => setCopied(false), 2000)
```

### 3. 响应式布局
```typescript
// ✅ 正确：使用 useBreakpoint
const isMobile = useBreakpoint('mobile')

return isMobile ? <MobileView /> : <DesktopView />

// ❌ 错误：手动检查
const isMobile = window.innerWidth < 768
```

### 4. 超时处理
```typescript
// ✅ 正确：使用 useTimeout
useTimeout(() => {
  showError('请求超时')
}, 10000)

// ❌ 错误：手动 setTimeout
setTimeout(() => {
  showError('请求超时')
}, 10000)
```

## 🎨 设计原则

### 1. 组合优于继承
使用 Hook 组合实现复杂功能，而不是创建复杂的组件层级。

### 2. 单一职责
每个组件只负责一个明确的功能。

### 3. 可配置性
通过 Props 提供灵活的配置选项。

### 4. 一致性
遵循统一的 API 设计和命名规范。

### 5. 可访问性
提供键盘支持、屏幕阅读器支持。
