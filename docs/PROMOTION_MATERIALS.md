AgentForge manages AI agents (like Claude, GPT, etc.) with a gaming twist:
- 🎮 **RPG Leveling:** Agents gain XP from tasks and level up (1-100)
- 🌳 **Skill Tree:** 30+ skills that apply real effects to execution

- 💰 **Token Tracking:** Visualize costs, set budgets, get alerts
- 🔔 **Notifications:** Desktop (Electron native) + browser + sound effects

- **Frontend:** React 18 + TypeScript 5 + Tailwind CSS
- **Desktop:** Electron 41 (cross-platform)
- **State:** Zustand with persistence
- **UI:** Framer Motion animations
- **Build:** Vite 6

- 67 production components
- 34,059 lines of TypeScript code
- 15 state stores, 8 core services

## The Problem

Managing multiple AI agents (Claude, GPT, custom agents) is:
- Boring and repetitive
- Hard to track costs (tokens)
- No motivation to optimize
- Difficult to compare agent performance

## The Solution

AgentForge adds game mechanics:

**1. RPG Leveling System**
- Agents gain XP from completed tasks
- Level 1 → 100 (+ prestige system)
- Visual level-up animations

**2. Skill Tree**
- 30+ skills across 5 branches
- Real effects: "Token Efficiency" reduces costs by 10%
- Strategic progression paths

**3. PVP Battle Arena**
- Turn-based combat between agents
- Attributes calculated from level + skills
- MMR ranking system (Bronze → Master)

**4. Token Economics**
- Real-time token consumption tracking
- Budget limits (daily/weekly/monthly)
- Visual dashboards with alerts
- Cost optimization suggestions

**5. Social Features**
- 6 leaderboards (Level, PVP, Tasks, Efficiency)
- 90-day seasons with rewards
- Invite codes with dual rewards

## Why It Works

Gamification drives behavior:
- ✅ You want to level up → optimize agents
- ✅ You compete on leaderboards → improve performance
- ✅ You unlock achievements → explore features

## 📝 常见问题准备

**Q: 这是付费产品吗？**
A: 不，AgentForge 是 100% 免费和开源的 (MIT License)。永远免费。

**Q: 支持哪些 AI 模型？**
A: 当前支持通过 OpenClaw Gateway 连接的所有模型。未来会添加更多集成。

**Q: 为什么要游戏化？**
A: 游戏机制驱动行为。升级、排行榜、成就让你自然地优化 Agent 和降低成本。

**Q: 数据存储在哪里？**
A: 本地存储 (LocalStorage + Electron Store)。你的数据完全在你的设备上。

**Q: 可以商业使用吗？**
A: 可以！MIT License 允许商业使用。

**Q: 如何贡献？**

**Q: 有 Docker 版本吗？**
A: 暂时没有，但计划在 v1.1.0 添加。

**Q: 支持团队协作吗？**
A: v1.0.0 是单机版。多人协作功能计划在 v1.1.0+。
