## 🔧 技术实现

### 1. 类型安全

所有 Hook 都提供完整的 TypeScript 类型定义：

```typescript
export function useDebounce<T>(value: T, delay: number = 500): T
export function useLocalStorage<T>(key: string, initialValue: T): [...]
export function useIntersectionObserver<T extends HTMLElement = HTMLDivElement>(...)
```

### 2. SSR 兼容

所有涉及浏览器 API 的 Hook 都包含 SSR 检查：

```typescript
if (typeof window === 'undefined') {
  return defaultValue
}
```

### 3. 性能优化

- 使用 `useRef` 存储回调函数，避免不必要的重渲染
- 使用 `useCallback` 和 `useMemo` 缓存
- RAF 优化高频操作
- 自动清理副作用（timers, listeners）

### 4. 浏览器兼容降级

```typescript
// IntersectionObserver 降级
if (typeof IntersectionObserver === 'undefined') {
  console.warn('IntersectionObserver is not supported')
  return
}

// Clipboard API 降级到 execCommand
if (!navigator?.clipboard) {
  document.execCommand('copy')
}
```

## 🎯 最佳实践总结

### 1. Hook 命名规范
```typescript
// ✅ 正确：use + 动词/名词
useDebounce, useToggle, useCopy

// ❌ 错误：无 use 前缀
debounce, toggle, copy
```

### 2. 类型定义
```typescript
// ✅ 正确：使用泛型
function useLocalStorage<T>(key: string, initialValue: T): [T, ...]

// ❌ 错误：使用 any
function useLocalStorage(key: string, initialValue: any): [any, ...]
```

### 3. SSR 安全
```typescript
// ✅ 正确：检查 window 存在
if (typeof window === 'undefined') return defaultValue

// ❌ 错误：直接访问
const width = window.innerWidth
```

### 4. 性能优化
```typescript
// ✅ 正确：使用 useRef 存储回调
const savedCallback = useRef(callback)
useEffect(() => { savedCallback.current = callback }, [callback])

// ❌ 错误：直接在 effect 中使用
useEffect(() => { callback() }, [callback])
```
