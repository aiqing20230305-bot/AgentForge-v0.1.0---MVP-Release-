## 🌟 AgentForge - Forge Your AI Dream Team

> **Forge your AI agents like legendary heroes** | 像锻造传奇英雄一样打造你的 AI Agent

AgentForge is a visual RPG-style builder for Claude AI agents with task management and auto-discovery capabilities.

**No config needed** - Start with 8 demo agents and 35 sample tasks out of the box!

---

## ✨ Key Features

🎮 **RPG Equipment System** - Drag & drop interface for building agent configurations
📋 **Task Management** - Assign and track tasks across multiple agents
🔍 **Auto-Discovery** - Automatically detect local OpenClaw instances
👥 **8 Demo Agents** - Pre-configured agents ready to use (ATLAS, CLIP, ORACLE, etc.)
📊 **35 Sample Tasks** - Example tasks to get started immediately
🎨 **Cyberpunk UI** - Modern, sleek interface with smooth animations
🌍 **Bilingual** - Full English and Chinese support

---

## 🚀 Quick Start

```bash
git clone https://github.com/Summonair/agentforge.git
cd agentforge
npm install
npm run electron:dev
```

**That's it!** You'll see 8 agents and 35 tasks immediately.
